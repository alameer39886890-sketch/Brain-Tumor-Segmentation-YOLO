# Brain Tumor MRI Segmentation using YOLO

An advanced computer vision project focused on detecting and segmenting brain tumors from MRI scans using state-of-the-art YOLO models.

## 🚀 Project Overview
This project processes medical brain MRI images to accurately identify and segment tumor regions. It transitions from traditional CNN architectures to modern YOLO-based segmentation for high-speed and precise inference.

## 🛠️ Technologies Used
- **Python**
- **YOLO** for object detection and image segmentation
- **OpenCV / Image Processing Libraries**
- **Google Colab** (Cloud Training Environment)

## 📂 Repository Contents
- `best.pt`: The trained YOLO model weights.
- `Untitled1_YOLO11_segmentation.ipynb`: The main Jupyter Notebook containing the training, validation, and inference pipeline.
- Sample MRI images for testing.

## 💡 Usage
1. Load the trained model (`best.pt`).
2. Run the Jupyter Notebook to process new MRI scans and visualize the segmentation masks.
